AutoBookmark Chrome Extension

Move your mouse to the very top edge of the screen to reveal your auto-hiding bookmarks bar! Crafted by the sinary.org developer team.

✅ Google Chrome ✅ Microsoft Edge ✅ Brave Browser ✅ Opera & Opera GX ✅ Vivaldi & Arc

🚀 How to Install & Test on Any Chromium Browser

To keep AutoBookmark 100% free without charging our users, we distribute directly via GitHub and the Microsoft Edge Add-ons Store (which installs seamlessly on Chrome and other Chromium browsers as well!).

1
Open your browser's extension manager:
chrome://extensions or edge://extensions or brave://extensions
2
Toggle ON Developer mode in the upper right corner.
3
Click the Load unpacked button in the top left.
4
Select the project root folder:
AutoBookmark (the folder containing manifest.json)
5
That's it! Open any web page (or refresh this page), and hover your cursor within the top 8px of the screen to reveal the floating bookmark bar!

⚡ Extension Features

✨ Smart Hover Trigger
Instantly slides down when mouse enters the top edge; smoothly hides when you move away.
📁 Nested Folders
Full dropdown navigation supporting multi-level folders and submenus.
📌 Pin Anytime
Press Alt + B or click the pin icon to keep the bar visible while working.
🔍 Quick Search
Instant fuzzy search across all your bookmarks right inside the floating bar.
🎨 4 Themes
Dark Glass, Modern Light, AMOLED Black, and Classic Chrome styles.
🛡️ Shadow DOM Isolated
Zero CSS conflicts with any webpage you visit.
